# Support

## Questions and help

Open a [GitHub Discussion](https://github.com/levimackay/codeatlas/discussions)
for usage questions, ideas, or anything that isn't a confirmed bug.

## Bug reports

Open a [GitHub Issue](https://github.com/levimackay/codeatlas/issues) with:

- Your OS and version
- CodeAtlas version (`codeatlas --version` or Settings → About)
- What you expected to happen and what actually happened
- Steps to reproduce, if you have them

## Security issues

Do not open a public issue. See `SECURITY.md` for how to report a
vulnerability privately.

## Feature requests

Open a GitHub Issue describing the problem you're trying to solve, not
just the feature you have in mind. `ROADMAP.md` has the current
direction; if what you want is already listed, add a comment there
instead of opening a duplicate.
